# JobSearch

This repository contains Java interview exercises and a Spring Boot web application.

## Requirements

- JDK 25
- Maven 3.6.3 or newer

## Run

Start the application with:

```powershell
mvn spring-boot:run
```

The health endpoint is available at `GET http://localhost:8080/api/v1/health`.
The employee creation route is currently a `501 Not Implemented` placeholder.

Run the test suite with:

```powershell
mvn test
```
